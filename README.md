# Task Foundry

Walk. Task. Automate.

An idle RPG where daily tasks, real steps, and a Factorio-style factory floor feed each other.

**Live (web):** https://azztech.online/apps/tf/

**Current OTA:** `1.1.25` · **Native APK base:** `1.1.0` (`online.azztech.taskfoundry`)

> GitHub still shows this repository as `hello-world` until it is renamed to **TaskFoundry** in
> Settings → General → Repository name. Cloud agent tokens cannot rename the remote.
